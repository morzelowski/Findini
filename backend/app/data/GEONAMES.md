# Miejscowości Polski

Źródło: [GeoNames, wyciąg PL](https://download.geonames.org/export/dump/), pobrany 10.11.2026. Licencja [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). © GeoNames i współtwórcy. Dane bez gwarancji kompletności i dokładności.

`places_pl.tsv.gz`: 45427 zamieszkanych miejsc (klasa P, bez historycznych, opuszczonych i części miejscowości). Kolumny TSV: identyfikator GeoNames, nazwa, szerokość, długość, województwo, powiat, populacja. Nazwy administracyjne z admin1CodesASCII/admin2Codes. Współrzędne wskazują środek miejscowości, a nie miejsce zdarzenia; użytkownik potwierdza punkt na mapie.

SHA-256 źródłowego PL.zip: `7022f4218888fc5157d636dfc7d1fa8f3b074769863f3b8414cc4f60d23f58a3`. Katalog jest dołączony do API i działa bez połączenia z GeoNames.
